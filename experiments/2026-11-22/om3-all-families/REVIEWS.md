# OM3 implementation and review record

Each arm was written by an implementing agent from the paper (reference code consulted only where the paper is silent, as each
file's docstring says) and checked by the standard harness (`test_arm.py`: parameter count within 3% of 471,264, forward vs
recurrent-step parity < 1e-4, exact causality, a 12-step training smoke, peak RSS < 2 GiB). Five arms then had an independent
paper-fidelity review (one reviewer per group: delta = gdn + titans, decay-attention = mlstm + retnet, rwkv7). The hybrid arms
(hyb, griffin) and hyena were checked by the harness and by their implementers' own extra tests only; they had no independent review.

## hyb

Implementer's summary of the mechanism: Jamba-style interleaved pre-norm residual stack [Mamba-2, attention+MLP, Mamba-2, attention+MLP], d=128, tied embedding (std 0.02), final RMSNorm. The Mamba-2 blocks are h + ob.OM2Mixer(signed=False, bcnorm=False)(RMS(h)), the om2bench m2 mixer: expand 2, 8 heads x P=32, N=32, conv4, a_t=exp(-dt*exp(A_log)), H_t=a_t H_{t-1}+dt x B^T, y=H C + D x, gated RMSNorm output; forward() uses the exact chunked SSD form and step() the recurrence. The attention blocks are ob.TFBlock (RoPE, 4 heads of 32, causal softmax attention, GELU MLP with ff=171, the width closest to the parameter target). The step() state is (pos, per-block caches): a (conv window, SSM state) pair for each Mamba block and a (K, V) cache for each attention block, carried side by side.

Independent review: none.

## griffin

Implementer's summary of the mechanism: Griffin residual blocks rec, rec, local-attn, rec. Each block runs RMSNorm -> temporal mix -> skip, then RMSNorm -> gated MLP W_d(GeLU(W_1 x)*(W_2 x)) with F=114 -> skip. Recurrent block (D_RNN=176): GeLU(W_y x) * RG-LRU(causal depthwise Conv1D k=4, no bias, applied to W_x x), then W_o. RG-LRU: r_t=sigmoid(W_a v+b_a) and i_t=sigmoid(W_i v+b_i), with block-diagonal gates in 16 blocks; log a_t=-c r_t softplus(-Lambda), i.e. a_t=sigmoid(Lambda)^(c r_t) with c=8, computed in log space; h_t=a_t h_{t-1}+sqrt(1-a_t^2)(i_t v_t). Lambda is initialised so that a^c~U[0.9,0.999] (measured 0.9000-0.9990); W_a and W_i use LeCun normal init. forward() runs the diagonal recurrence with ob.scan_doubling, in 1024-step spans with the state carried across spans beyond that; step() runs the explicit recurrence. Local attention is multi-query: 4 query heads of 32 share one key/value head, with RoPE and a 64-token sliding window (token t sees t-63..t, verified exactly). step() keeps a rolling 64-entry KV cache, so the decode state has constant size.

Independent review: none.

## gdn

Implementer's summary of the mechanism: Gated DeltaNet token mixer in 4 pre-norm blocks (ob.SSMLM: tied byte embedding with std 0.02, final RMSNorm, no MLP). Each block has 4 heads with d_k 32 and d_v 48. Paths: q and k go linear -> causal depthwise conv4 (no bias) -> SiLU -> L2 norm, with q scaled by 1/sqrt(d_k); v goes linear -> conv4 -> SiLU. Gates: beta = sigmoid(W_b x) and alpha = exp(-softplus(W_a x + dt_bias) * exp(A_log)). Recurrence: S_t = alpha_t (S_{t-1} - beta_t (S_{t-1} k_t) k_t^T) + beta_t v_t k_t^T, read o_t = S_t q_t. Output: per-head RMSNorm(o) * SiLU(W_g x), then W_out. forward() uses the paper's chunkwise WY / UT-transform form with C = 64, and (I + A)^{-1} is an exact unit-triangular solve. step() runs the plain recurrence, carrying the conv window and S. Params: 470,880 (-0.08% vs 471,264). Decode 2.84 ms per token, prefill 9,402 tok/s.

## titans

Implementer's summary of the mechanism: Titans-style MAG. Four learnable persistent tokens are prepended once (positions 0-3) and their outputs dropped. In each of 4 pre-norm blocks, with u = RMSNorm(h): (a) y = sliding-window causal attention, 4 heads x 32, RoPE, window 64 (query i sees i-63..i) plus the always-visible persistent prefix. (b) m = W_O M(u), a linear associative memory per head (2 heads, M and S are 32 x 32): q, k, v = SiLU(conv4(W u)), with q and k L2-normalised; alpha, eta, theta = sigmoid(linear(u)) per token and head, initial alpha 1e-3 / 1e-2, eta 0.5, theta 0.05. Update: grad = 2 (M_{t-1} k_t - v_t) k_t^T; S_t = eta_t S_{t-1} - theta_t grad; M_t = (1 - alpha_t) M_{t-1} + S_t; read y_t = M_t q_t after the write. (c) Learned gate o = RMSNorm_y(y) * sigmoid(RMSNorm_m(m)); h += o. (d) Small GELU MLP, hidden 36. forward() solves the per-token recurrence exactly in chunks of 32: the errors e_t = v_t - M_{t-1} k_t come from one unit-triangular solve whose coefficients are built from products of decay and momentum. step() runs the plain recurrence and carries the prefix and window KV cache (last 64 tokens), the conv window, M and S. Params: 471,704 (+0.09%). Decode 5.78 ms per token, prefill 6,188 tok/s.

## mlstm

Implementer's summary of the mechanism: xLSTM[1:0] stack of 4 pre-norm residual mLSTM blocks (d=128). Each block: LayerNorm, then an up-projection to 2 x 256. One branch goes through a causal depthwise conv (k=4) and swish, feeding block-diagonal 4x4 q/k maps; v is mapped from the pre-conv branch. Gates come from [q;k;v], one scalar per head (4 heads of width 64). Cell: matrix memory C_t = f_t C_{t-1} + i_t v_t k_t^T and n_t = f_t n_{t-1} + i_t k_t, read out as h_t = C_t q_t / max(|n_t^T q_t|, 1), with k scaled by 1/sqrt(64). Input gate is exp, forget gate is sigmoid, with the log-space stabiliser m_t = max(log f_t + m_{t-1}, i~_t). After the cell: per-head GroupNorm (weight, no bias), plus a learnable skip times the conv output, gated by swish(z) from the second branch, then a 256->128 down-projection. Embedding is tied (std 0.02), with a final LayerNorm. forward() uses the exact stabilised parallel form: log D_ij = sum_{j<s<=i} log f_s + i~_j, a row-max stabiliser, and normaliser max(|row sum|, exp(-m)) + 1e-6. It runs through an autograd.Function with a hand-written exact backward. step() uses the stabilised recurrent form with state (conv window, C', n', m), m_0 = -inf.

Independent review verdict: **ok**

## retnet

Implementer's summary of the mechanism: 4 pre-LN RetNet layers (d=128): Y = MSR(LN(X)) + X, then X' = FFN(LN(Y)) + Y with FFN = gelu(X W1) W2 at width 106. Gated multi-scale retention uses 4 heads with gamma_h = 1 - 2^(-5-h) (0.96875, 0.984375, 0.9921875, 0.99609375), key and value head width 32. Rotary (xPos-style) rotation on q and k with RetNetRelPos angles 1/10000^linspace(0,1,16); k is scaled by 1/sqrt(32). Parallel form: (Q K^T o D) V with D_nm = gamma^(n-m) for n>=m. Recurrent form: S_n = gamma S_{n-1} + k_n^T v_n, o_n = q_n S_n. The paper's normalisations (D~ = D / sqrt(row sum), R~ = R / max(|row sum|, 1)) are applied identically in both forms; the recurrent version uses c_n = gamma c_{n-1} + 1 and z_n = gamma z_{n-1} + k_n. Then per-head GroupNorm (no affine, eps 1e-6), swish(X W_G) gate and W_O. Embedding is tied (std 0.02), with a final LayerNorm.

Independent review verdict: **ok**

## rwkv7

Implementer's summary of the mechanism: RWKV-7-style model: 4 blocks, d_model 128, 2 heads of size 64, per-layer state 2x64x64. Time mixing per layer: static learned token-shift lerps lerp(x_t, x_{t-1}, mu) for r, decay, k, v, a and g. Projections r = x W_r, k = x W_k, v = x W_v. Vector decay w_t = exp(-e^-0.5 * sigmoid(w0 + tanh(x A_d) B_d)), so every channel lies in (0.545, 1). In-context learning rate a_t = sigmoid(a0 + x A_a B_a). Value residual for layers 1-3: v <- lerp(v, v_layer0, sigmoid(v0 + x A_v B_v)). Output gate g = sigmoid(x A_g) B_g. Removal key kh = per-head L2-normalised (k * k_k). Replacement key kt = k * (1 + (a - 1) * k_a). Generalised delta-rule state update S_t = S_{t-1}(diag(w_t) - kh^T (a * kh)) + v^T kt. Output: per-head GroupNorm (eps 64e-5) of r S^T, plus the bonus (sum over the head of r * r_k * kt) v, times the gate, then the output projection. Channel mixing is relu(lerp(x', x'_{-1}, mu') W_k)^2 W_v. Blocks use pre-norm LayerNorms (LN0 on the embedding in block 0, LN1, LN2). The model has a tied embedding and a final RMSNorm. forward() evaluates the recurrence exactly with a chunked (L=16) diagonal-plus-low-rank WY form: a unit-lower-triangular solve per chunk, then a chunk-to-chunk loop of T/16 steps. step() runs the token-by-token recurrence with state (previous LN1 output, previous LN2 output, S) per layer. Against a token loop in float64 the chunked kernel agrees to about 1e-13, including all input gradients, for T in {1, 5, 17, 77, 80, 255, 256}, and is bitwise causal.

## hyena

Implementer's summary of the mechanism: Hyena operator of order N=2, built literally from Definition 3.1 and Algorithms 1-3. (1) Projection: Linear d->3d with bias, then a causal depthwise conv (k=3, with bias) on every channel, split into x1, x2, v. (2) Two implicit long filters h1, h2 covering the whole context: a positional encoding (normalised t plus cos/sin of K=8 complex exponentials, 17 features), a 4-layer FFN of width 64 with sine activations (one trainable frequency vector, init 14), output reshaped to (N, d, L), times the window exp(-alpha_c t) + 0.05. (3) Recurrence z1 = v, z_{n+1} = x_n * (h_n conv z_n + Dskip_n * z_n), then out_proj (d->d, bias), so y = W_out(x2 * (h2 conv (x1 * (h1 conv v)))). forward() runs each long conv as a causal FFT convolution padded to 2T, through a custom autograd Function: float64 forward FFT, float32 backward as a correlation via FFT of the same size. step() keeps the last two projected inputs and the full history of z1 and z2, and evaluates each long conv as an exact direct sum over that history. Block: x + Hyena(RMS x), then x + GELU FFN (width 64, no bias). LM: tied byte embedding (std 0.02), 4 blocks, final RMS. Extra checks I ran on the test machine: custom backward vs plain float64 autograd gives a max relative gradient difference of 5.2e-7 over all 78 parameters. In a 300-step run of the benchmark recipe (warmup 100, lr 3e-3, AdamW 0.9/0.95), training loss over steps 251-300 was 2.97 bits/byte, against 3.19 for the tf arm in my own run with the same seed and data; this is a sanity check, not a ranking. After those 300 steps, parity was 1.05e-5 (T=96) and 7.6e-6 (T=256), and causality leakage was exactly 0.

Independent review: none.
