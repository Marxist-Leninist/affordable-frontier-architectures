# Reproduction and archival scope

Private repository delivery retains tested source, protocols, data/checkpoint/source hashes, aggregate results, complete timing records, test output and independent audit. Reproduce in sibling directories named frontier_research_v19, frontier_research_v23 and frontier_research_v24 as documented; restore older source archives first where needed.

Dataset rows and checkpoint weights are excluded. train_starts.npy is regenerated by run.py --freeze; losses.npz is regenerated by run.py and remains in the complete local bundle. The repository original_artifact_manifest.json records the full local run and may name these omitted binaries. Do not treat absent binary files as present. Reproduction requires separate lawful data access and inherited training, not merely installing dependencies.

The fixed original timing.py is retained for protocol verification; use timing_distribution.py, with the documented pre-timing softmax amendment, for the reported measurements. Training was not rerun after the interruption in report preparation.
