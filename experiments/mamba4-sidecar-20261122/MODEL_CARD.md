# Bounded-retrieval selective recurrence prototype, v1 (unofficial “Mamba-4” idea)
- Intended for research and reproducibility on a frozen synthetic key–value observation benchmark. Not a language model, vendor Mamba release, deployment backend, or memory-safety system.
- Original standalone NumPy implementation with 15,372 model scalars (verify arrays), trained using only procedural records. The selective update is input-gated diagonal recurrence. Optional external FIFO returns exact records if present and from the correct epoch. The learned trigger is a logistic expected-benefit gate, not a Transformer or full Mamba. The wider recurrence comparison is separate.
- Output files `model_{17,29,43}.npz` contain numeric `u,g,w,b,gate_mean,gate_sd,gate_w`; `wide_{17,29,43}.npz` contain numeric `u,g,w,b` only. No pickle objects, user-provided data, auth/config secrets, or external executable dependencies beyond NumPy.
- Holdouts are unseen RNG streams and shifted length/location/distractors, not natural language. In that shifted fixture recurrence 69.19%, wider recurrence 69.53%, learned gate 80.42% at 36.28% read rate, always-read 82.17%. Four-slot prepared local table was actually faster to read unconditionally.
- Reproduce with `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python pilot.py --verify` and `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python wide_control.py --verify`. Runtime timings are host-specific and not replay gates.
