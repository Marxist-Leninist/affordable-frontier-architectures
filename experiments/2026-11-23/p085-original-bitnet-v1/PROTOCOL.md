# P085 mini from-scratch 2023 original BitNet v1 vs matched FP32 Transformer

Primary equations: Wang et al. 2023 arXiv:2310.11453v1 (https://arxiv.org/html/2310.11453v1), sections 2.1–2.2, Appendix A. This is an implementation of the original W1A8 ideas, NOT ternary b1.58, a Microsoft checkpoint benchmark, or a direct replication of its 125M–30B results. Mini four-layer causal Transformer width192, four heads, context128 bytes, FFN4×, learned positional table, untied high-precision FP32 token embedding and vocabulary head, ordinary GELU and SDPA, matched SubLN placements (normalized inputs before projections incl attention output and FFN output) and projection parameters 1,903,488 overall both arms. No dropout or gradient clipping. Both FP32 masters and FP32 AdamW (.9,.98), decay.01, same warmup/schedule/positions. FP32 dense arm is otherwise same small implementation, not the publication's native FP16 baseline. No third packed4 arm (different high-precision architecture and optimizer baseline).

BitLinear computes strictly positive centered master ->+1 else −1; beta=mean(abs uncentered master), SubLN then signed absmax A8 using Q=128. One calibration group on this device per actual projection, per-tensor gamma training, per-token gamma in validation/test/prefill using inference semantics to preserve causality. Nearest-even integer round to [-127,127] for signed paths (clip edge convention, explicit adaptation of epsilon) with zero-norm safe scale. For pre-GELU Eq6, min-shift x, use raw absmax gamma as written, quantized nonnegative codes 0..127, then dequantize and restore affine offset before ordinary GELU. The publication does not fully specify rounding/order or exact affine nonlinear implementation and this is our named fixed convention; not assumed all replicators use it. Both scales detached, identity STE through reconstructed weights/activations; an implementation choice for gradients not drift of forward equations. CUDA uses ordinary FP32 PyTorch fake-quant matmul, no custom binary kernels, no energy/watt or native speed claim. Per-tensor scales during training can couple tokens/batches; do not use this for validation/test or claim strict training-time local causality. Exact inference prefix invariance required on both arms.
