## Fixed selection and causal intervention

The final pre-score protocol uses original observed history only. At target byte t=1921..2048 (zero-based), query context is raw[t-8:t]. A matching earlier context has follower index j; eligibility requires at least one fully observed context/follower pair with 8<=j<1408 and j<t-512. No complete matching pair may start at or after t-512 and have follower before t. The target raw[t], its identity, and loss are not inputs to selection. Matches crossing the dynamic suffix boundary do not count as fully inside; matches in the preserved middle may remain. The first1408-byte donor intervention therefore changes a region containing known matching history, without guaranteeing removal of every match or every relevant follower. The definition does not require any earlier follower to equal the current target.

The parent clarified the stricter follower<1408 bound before freeze/scoring; this is recorded in design_clarifications.json. The selected cohort is not a scan for targets on which any model succeeds. Protocol chronology is supported by observed messages and saved lock files, not independently established by filesystem timestamps.

Donors are deterministic next eligible rows with different full-document hashes. All128 targets and513 genuine input bytes before the earliest target are preserved (final641 bytes). Input output1920 predicts target1921. Neural suffix512 begins at original input1536 and provides385–512 history bytes at scored targets; copy suffix is a dynamic last512 observed-byte memory. These are different capability ablations, explicitly disclosed, and must not be called identical contexts. suffixCopyOnly isolates copy-history reduction while keeping original neural losses fixed.
