# Preregistered exploratory protocol and correction

Read latest repository main and v6 before choosing retained-Adam mixed contexts. Fixed three seeds, two matched architectures, three context arms. This differs from v24's earlier Transformer-only mixed context and from v5/v6 optimizer controls: both signed and attention now retain Adam, and mixing occurs within every update with identical full target ledgers.

The initial v7 pilot had a correctness defect caught by independent review: loading shared optimizer-state tensors into successive arms allowed source state mutation. It was stopped; all pilot numerical results are invalid and excluded. The corrected run deep-copies state for every arm. An independent unit test verifies one fork's updates cannot mutate the source or another fork; final checkpoint tests require every arm to finish at exactly1000 Adam steps. Historical retained512 losses must replay exactly for all six model/seed pairs. v6 is unaffected because only one retained arm loaded the source state; its reset arm used independent fresh state.

The invalid pilot completed three attention seed1 continuations and one reconstruction, at least2,048,000 target presentations. A possible partial next reconstruction before interruption was not instrumented, so this is a lower bound. Archived invalid outputs are local only, not evidence for any conclusion. Corrected execution had an external900-second hard cap. Performance profiling runs only after quality training ends; no competing audit benchmark.

No scalar optimum or strict noninferiority threshold was prespecified. Report all four heldout metrics and all three context arms, including tradeoffs and seed ranges. A lower mean is not proof of broad superiority; repeated small frozen heldouts and correlated web windows remain exploratory. Equal target budgets/optimizer updates are not equal compute. Different shape layouts and sequence boundaries are part of the operational intervention.
