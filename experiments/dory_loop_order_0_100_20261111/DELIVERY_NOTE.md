# Code and results attachment

This attachment contains code, numerical results, reports and figures for the completed Dory-inspired loop-order and 0–100 inference experiment. The 18 full model checkpoints are omitted to keep the attachment small. CHECKPOINT_MANIFEST.json identifies them; obtain them from the separately verified public repository publication.

FILE_MANIFEST.json describes only files in this attachment, excluding itself. PUBLIC_RELEASE_MANIFEST.json describes the full repository release including checkpoints; it is not a claim that those weights are attached here. The original root README and report provenance refer to the full release. Regenerating the strict topology report requires those checkpoint files for hash verification. No raw corpus is included.
